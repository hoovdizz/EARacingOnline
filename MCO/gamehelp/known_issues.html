  Patching  
  3/22/02
 Patching will be difficult through firewalls or routers. Make sure you have your firewall and/or router configured correctly. To assist in the diagnosis and solution, use the port checker to check that the appropriate ports are opened, and use the proxy config tool to correctly direct the game to the proxy address. These are in the trouble shooting menu available from the login dialog.

  

    
  Exception Violation Errors & "MCO is already running" Error Message  
  7/25/02
 Please make sure you have fully updated all your hardware drivers and reinstall the most current version of Microsoft's DirectX. Please also use the Windows Update option from the Start Menu and update Windows as necessary. Scan your computer with a current anti-virus program. If you continue to experience this issue, please run "dxdiag.exe" from the Start Menu and save the diagnostic information (dxdiag.txt). Contact Tech Support and attach the dxdiag.txt file, your system specs (hardware, driver versions, dx version, etc.), and exact error message you received.

  
  Windows XP Pro & Opening Video Hang  
  3/22/02
 If you have Windows XP Pro and hang on MCO's opening video, make sure you have the correct version of the DirectX DLL's selected. Check your settings in Control Panel... DirectX... Direct3D. You should have the Retail Version selected, not the Debug Version. Some cards do not run correctly with the Debug Version of DirectX DLL's. You can always simply remove the movies from the movies folder for them to be bypassed.

  
  Login Security Issues  
  11/29/01 If you are having login problems, try the following internet browser security settings adjustment:

  1. Click on Windows Start button, choose Settings, choose Control Panel.
  2. Double Click on Internet Options.
  3. In the Security tab, click on the Trusted Sites icon and then click on the Sites... button.
  4. Enter https://www.ea.com in the field provided and then click on the Add button.
  5. Click on the OK button.
  6. Click on the Custom Level button.
  7. Make sure the field under Reset Custom Settings pull-down is set to Low.
  8. Click on the OK button.
 
  Multiple Browsers in Windows ME  
  11/28/01 If you are using Windows ME and use more than one browser (like Netscape 6.0) you may have problems patching completely and logging in. If you have multiple browsers installed, make sure the settings of the default browser match IE settings if different than IE.

  

    
  Create Race with LinkSys BEFSR41 Router / Switch  
  7/25/02
 There is a known issue with creating race pits in MCO while using the LinkSys BEFSR41 Internet router/switch. This router should not affect joining races, but players using this router will not be able to create race pits without being disconnected from MCO. We apologize for this inconvenience.

  

    
  Norton Anti Virus / Zone Alarms & Multi-player Races  
  1/25/02
 Running these programs while playing MCO may cause problems when attempting to join or host multi-player races. For optimal game performance, we recommend these programs be disabled prior to running MCO. For more information about Zone Alarm, please refer to our Knowledge Base.

  
  Game Crash  
  12/12/01 Some users are crashing out of the game at random moments. We are looking into the problem and will let you know when we’ve tracked it down.

Possible Fix:
  • Update VIA chipset motherboards to the 4 in 1 drivers.
  • Update to a more recent video driver.
  • Set audio to Stereo instead of EAX (in Options menu).
  
  Windowed Mode/Alt + Tab  
  7/25/02
 Some and video cards have problems running in windowed mode or with using alt + tab. This can often be remedied by setting the desktop resolution to 16 bit rather than 32 bit or reinstalling MCO.

  
  Background Programs  
  10/31/01 Programs like AIM, ICQ, and Yahoo Messenger may pop-up windows when new messages arrive. If this happens while playing Motor City Online in full-screen mode, the game will freeze. Please disable any messaging programs, or any background program that may open new windows, before starting Motor City Online in full-screen mode.

  
  Game Freeze  
  11/30/01 If you have a Ge-Force 2 or 3 video card with ALI and VIA (AMD) main board chipsets and are experiencing game freezes in Motor City Online, check out this possible fix.

  
  ATI Rage Pro & Hercules Kyro II Video Cards  
  11/28/01 These cards are currently having some problems, which may be related to your desktop resolution. We are investigating.

  
  Aventail  
  10/31/01 Remote access programs such as PC Anywhere or Aventail may cause framerate and multiplayer positional problems with Motor City Online. Disabling or uninstalling these programs may correct these problems.
