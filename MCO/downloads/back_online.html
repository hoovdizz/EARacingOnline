Motor City Online Is Back Online

Packaged with Update 16 Version 1.0.151
24 Aug 2026

This rebuilt installation bundle contains Motor City Online as it existed on the packaged date above. It was packaged by EAO_Lix as a way of giving back to the community.

Installation

Extract or mount the package, then run:

Install-MCO-Rebuilt.bat

The default installation folder is:

C:\Program Files (x86)\EA Games\Motor City Online

The installer is designed to run directly from read-only ISO media.

What the Installer Does

  1. Copies the complete, already-updated Motor City Online game folder.
  2. Clears read-only attributes inherited from ISO media.
  3. Installs and registers the required legacy DAO 3.51 / Jet 3.5 database components.
  4. Applies the captured Motor City Online, EA, and 3D Setup registry settings.
  5. Applies the NovaServ connection settings.
  6. Installs server.crt into the Local Computer Trusted Root Certification Authorities store.
  7. Configures mcity.exe and mco-launcher.exe to give you the option to set the launcher to run as Administrator every time (This is optional).
  8. Creates Desktop and Start Menu shortcuts that launch mco-launcher.exe using mcity.ico.

Read-Only Media Support

Logs, registry payloads, receipts, and runtime files are not written back to mounted ISO media.

Installer and repair logs:

C:\ProgramData\MCO New Age Install\Logs\

Installation receipt:

C:\ProgramData\MCO-Rebuilt-Installer\install.json

Temporary embedded registry files are written to %TEMP%. After the game is copied, the installer recursively clears the read-only attribute from the selected installation directory.

Movie Skip and Optional Widescreen

Movie Skip is installed by default. The Widescreen Hack is not installed automatically; it remains optional, and the installer displays a reminder that its files are available in:

Payload\Optional

First Run

After the core installation finishes, the installer shows the optional Widescreen Hack reminder, opens 3DSetup.exe as Administrator, waits for 3D Setup to close, and then starts mco-launcher.exe as Administrator.

Repair and Uninstall

To repair only the legacy database components on an existing installation, run:

Repair-MCO-Database.bat

To remove the MCO-specific installation, shortcuts, compatibility entries, NovaServ settings, and installed certificate where appropriate, run:

Uninstall-MCO-Rebuilt.bat

Shared DAO / Jet components are intentionally retained so other legacy applications that depend on them continue to work.

Package Notes

This rebuild avoids the original Motor City Online InstallShield/setup executable and other ancient installers. The BaseGame payload contains the already-installed and already-updated game files.

The package root includes mcity.ico and autorun.inf, which identify supported ISO media as "MCO New Age Install."
